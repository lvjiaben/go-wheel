# 多语言 (i18n)

项目支持多语言国际化，通过 `Accept-Language` 请求头自动识别语言。

## 配置文件

多语言文件位于 `configs/i18n/` 目录：

```
configs/i18n/
├── zh-CN.yaml    # 中文
└── en-US.yaml    # 英文
```

### 文件格式

```yaml
# configs/i18n/zh-CN.yaml
common:
  success: "操作成功"
  error: "操作失败"
  
api:
  user:
    login_success: "登录成功"
    login_failed: "用户名或密码错误"
    
backend:
  admin:
    create_success: "管理员创建成功"
```

## 中间件

i18n 中间件自动解析请求头中的语言设置：

```go
// pkg/middleware/i18n.go
func I18nMiddleware(c *container.Container) gin.HandlerFunc {
    return func(ctx *gin.Context) {
        lang := ctx.GetHeader("Accept-Language")
        // 解析语言...
        ctx.Set("lang", lang)      // 设置语言代码
        ctx.Set("isCn", lang == "zh-CN")  // 是否中文
        ctx.Next()
    }
}
```

## 使用方法

### 在控制器中使用

```go
func (c *UserController) Login(ctx *gin.Context) {
    // 方式1：使用 http 包的国际化响应
    http.SuccessWithI18n(ctx, "api.user.login_success", data)
    http.ErrorWithI18n(ctx, "api.user.login_failed", nil)
    
    // 方式2：手动翻译
    msg := middleware.Translate(c.container, ctx, "api.user.login_success")
}
```

### 获取当前语言

```go
func (c *MyController) MyMethod(ctx *gin.Context) {
    // 获取语言代码
    lang := ctx.GetString("lang")  // "zh-CN" 或 "en-US"
    
    // 判断是否中文
    isCn := ctx.GetBool("isCn")
    if isCn {
        // 中文逻辑
    } else {
        // 英文逻辑
    }
}
```

### 直接指定语言翻译

```go
// 指定语言翻译
msg := middleware.TranslateWithLang(container, "common.success", "en-US")
```

## HTTP 响应国际化

使用 `http` 包的国际化方法：

```go
import "github.com/lvjiaben/go-wheel/pkg/http"

// 成功响应（自动翻译）
http.SuccessWithI18n(ctx, "common.success", data)

// 错误响应（自动翻译）
http.ErrorWithI18n(ctx, "api.user.not_found", nil)

// 带参数的翻译
http.SuccessWithI18n(ctx, "api.user.welcome", gin.H{
    "name": username,
})
```

## 添加新语言

1. 创建语言文件 `configs/i18n/ja-JP.yaml`

2. 修改中间件支持新语言：

```go
// pkg/middleware/i18n.go
if lang == "ja" || lang == "ja-JP" {
    lang = "ja-JP"
}
```

## 翻译 Key 命名规范

```yaml
# 模块.功能.具体描述
api:
  user:
    login_success: "登录成功"
    login_failed: "登录失败"
    
backend:
  admin:
    list_success: "获取列表成功"
    create_success: "创建成功"
    update_success: "更新成功"
    delete_success: "删除成功"
    
common:
  success: "操作成功"
  error: "操作失败"
  not_found: "数据不存在"
  unauthorized: "未授权"
```

## 前端配合

前端请求时设置 `Accept-Language` 请求头：

```typescript
// axios 配置
axios.defaults.headers.common['Accept-Language'] = 'zh-CN';

// 或在请求拦截器中设置
axios.interceptors.request.use(config => {
  config.headers['Accept-Language'] = localStorage.getItem('lang') || 'zh-CN';
  return config;
});
```
