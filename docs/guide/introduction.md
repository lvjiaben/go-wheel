# 介绍

Go-Wheel 是一个基于 Go + Gin + Vben Admin 的企业级后台管理系统，提供完整的前后端分离解决方案。

## 特性

### 🚀 现代技术栈

- **后端**: Go 1.21+、Gin、GORM、Zap、Viper
- **前端**: Vue 3、Vite 5、TypeScript、Ant Design Vue
- **数据库**: MySQL 5.7+ / PostgreSQL 12+
- **缓存**: Redis 6.0+
- **消息队列**: RabbitMQ 3.8+

### 🔐 完善的权限系统

- RBAC（基于角色的访问控制）权限模型
- JWT Token 认证
- 接口级权限控制
- 数据权限隔离

### 📦 丰富的内置功能

| 功能模块 | 说明 |
|---------|------|
| 用户管理 | 用户增删改查、状态管理 |
| 角色管理 | 角色权限分配 |
| 菜单管理 | 动态菜单、按钮权限 |
| 配置管理 | 系统参数配置 |
| 附件管理 | 文件上传、分组管理 |
| 代码生成 | 可视化生成 CRUD 代码 |
| 定时任务 | Cron 表达式、分布式锁 |
| 消息队列 | RabbitMQ 集成 |
| WebSocket | 实时通信 |

### 🔧 开发友好

- 统一的代码规范
- 完善的日志系统
- 配置热重载
- 熔断器保护
- 优雅关闭

3. **易于扩展** - 模块化设计，松耦合架构

5. **社区活跃** - 基于主流技术栈，社区支持好

## 快速体验

```bash
# 克隆项目
git clone <repository-url>

# 启动后端
cd go-wheel
cp configs/config.example.yaml configs/config.yaml
go run main.go

# 启动前端
cd vben-admin
pnpm install
pnpm dev:admin
```

访问 http://localhost:5666 即可体验系统。
