# 联系我们

## 技术支持

如果您在使用过程中遇到问题，可以通过以下方式获取帮助：

### GitHub Issues

提交 Issue 是获取帮助的最佳方式：

1. 访问项目的 GitHub 仓库
2. 点击 "Issues" 标签
3. 点击 "New Issue" 创建新问题
4. 详细描述您遇到的问题

**提交 Issue 时请包含：**

- 问题的详细描述
- 复现步骤
- 期望的行为
- 实际的行为
- 错误日志（如有）
- 系统环境信息

### 贡献代码

欢迎提交 Pull Request 来改进项目：

1. Fork 项目到您的账号
2. 创建功能分支 `git checkout -b feature/xxx`
3. 提交更改 `git commit -m 'Add xxx'`
4. 推送分支 `git push origin feature/xxx`
5. 创建 Pull Request
